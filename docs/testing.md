
## Текстовый редактор

Создать документ с кириллицей и переносами; сохранить дважды и убедиться, что запись одна. Перезагрузить страницу и открыть через библиотеку. Проверить поиск без учёта регистра, статистику, импорт UTF-8 TXT и скачивание, пустой документ, подтверждение замены несохранённых данных. Удалить тестовую запись. При отключении API сохранить текст через скачивание.

## Органайзер

Загрузить задачи, создать задачу без срока, с прошедшим сроком и со сроком сегодня. Изменить приоритет, отметить выполненной, проверить фильтры, поиск и счётчики. Перезапустить сервер, загрузить список. Удалить тестовую задачу. При ошибке сохранения введённая форма остаётся.

## Атрибуты файлов

Загрузить тестовый TXT, изменить имя, ReadOnly и время. Сверить свойства самой копии в backend/data/files. Скачать и сравнить содержимое. На Windows проверить Hidden; на Linux переключатель недоступен. Исходник вне папки приложения не меняется. Перезагрузить сервер и загрузить список копий.

## Smoke test

После dotnet build выполнить python3 scripts/smoke_test.py. Скрипт проверяет создание/обновление/удаление документов и задач, пустой текст, некорректные поля, календарные даты, PNG-проекты, загрузку файлов, переименование, ReadOnly, timestamp, запрет выхода из папки, скачивание, а также сохранность после перезапуска. Сервер и данные изолированы во временной папке; тест не обращается к рабочему порту 5080. Визуальные и звуковые проверки этот тест не заменяет.
