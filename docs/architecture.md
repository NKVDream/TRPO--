# Как работает FORUM Workspace

## Общая схема

```text
Браузер: React
  App → Sidebar / HomePage / Editor / Player
                      │
               api/client.js (fetch)
                      │ HTTP /api/projects
                      ▼
ASP.NET Core: ProjectsController
                      │
                ProjectService
                      │
               ProjectRepository
                      │ SQL с параметрами
                 HubDatabase
                      │
                data/hub.db (SQLite)
```

## Запуск сервера

`backend/Program.cs` собирает приложение: регистрирует контроллеры и зависимости, создаёт таблицы при первом запуске и подключает маршруты. `AddControllers()` находит классы контроллеров, `MapControllers()` включает маршруты из их атрибутов. `UseStaticFiles()` отдаёт собранные JS/CSS из `wwwroot`, а `MapFallbackToFile()` отдаёт страницу React для остальных путей.

Контроллеры получают сервисы через конструктор. Это внедрение зависимостей: ASP.NET сам создаёт `ProjectsController`, передаёт ему `ProjectService`, тому — `ProjectRepository`, а репозиторию — `HubDatabase`. `AddScoped` создаёт экземпляр на HTTP-запрос, `AddSingleton` — один на приложение. Singleton HubDatabase хранит строку подключения, а каждое SQL-действие открывает и закрывает своё соединение.

## Сохранение рисунка по шагам

1. Пользователь рисует в HTML canvas. Координаты указателя пересчитываются в координаты холста 1200×720. Действия и история отмены живут в браузере.
2. По кнопке сохранения Editor превращает canvas в PNG data URL и вызывает `saveProject` из API-клиента.
3. Клиент отправляет `PUT /api/projects/{id}` с JSON `{name,content}`. Новый UUID создаётся при каждом сохранении: это отдельный снимок, а API умеет обновлять существующий id.
4. Атрибут `[HttpPut("{id}")]` направляет запрос в `ProjectsController.Save`. `[ApiController]` проверяет модель запроса: обязательные поля и длину названия. При ошибке возвращается HTTP 400 с описанием проверки.
5. `ProjectService` проверяет ограничения размера и PNG-префикс. Это базовая проверка формата запроса, не полноценная проверка содержимого PNG.
6. `ProjectRepository` выполняет INSERT/UPDATE с параметрами через Microsoft.Data.Sqlite. PNG хранится текстом вместе с названием и временем обновления.
7. Ответ 200 возвращается в браузер, Editor показывает сообщение. При недоступности сервера остаётся экспорт PNG.

Чтение устроено аналогично: список запрашивается без содержимого рисунков, а `GET /api/projects/{id}` возвращает конкретный рисунок. Неизвестный id даёт 404.

## Навигация и модули

`main.jsx` только подключает CSS и монтирует App в HTML-элемент root. App читает часть адреса после `#`: `#home`, `#editor`, `#player`. Изменение hash переключает видимый раздел без перезагрузки страницы.

`modules/registry.js` описывает название, иконку и компонент каждого модуля. Sidebar строит меню, HomePage — карточки, App — отображение компонентов. Добавление модуля описано в modules.md.

Готовые модули остаются смонтированными и скрываются атрибутом hidden. Поэтому музыка продолжает играть при переходе в редактор, а рисунок не исчезает. Перезагрузка страницы сбрасывает состояние браузера: рисунок нужно заранее сохранить.

## Проигрыватель

Player использует стандартный HTML audio. Выбранные пользователем File превращаются через URL.createObjectURL в временные браузерные адреса; audio читает их локально. React управляет плейлистом, текущим треком, громкостью и кнопками. События audio обновляют время, длительность и состояние воспроизведения.

У проигрывателя сейчас нет серверного контроллера: он не отправляет музыку и не сохраняет плейлист в БД. При удалении трека и размонтировании временные URL освобождаются. После перезагрузки файлы нужно выбрать заново.

## Разработка и собранное приложение

В разработке Vite обслуживает React на 5173 и перенаправляет `/api` на C# порт 5080 (vite.config.js). При едином запуске сборка frontend/dist копируется в backend/wwwroot: страницу и API обслуживает C# на 5080. Команды приведены в README.

Изначально маршруты API были объявлены в Program.cs через Minimal APIs. Сейчас они перенесены в контроллеры; адреса, схема БД и пользовательский интерфейс сохранены.

## Форматирование

Из корня репозитория:

```bash
npm run format --prefix frontend
npm run format:check --prefix frontend
dotnet format backend/Hub.csproj --no-restore
```

Prettier форматирует JSX, JS, CSS и конфигурацию фронтенда. dotnet format — C#. После изменения исходников пересоберите приложение, прежде чем проверять единый запуск.
