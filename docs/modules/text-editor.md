# Текстовый редактор

Модуль `text`, адрес `#text`. Редактирует обычный текст UTF-8, открывает и скачивает TXT, сохраняет именованные документы в SQLite, открывает и удаляет их из библиотеки. Считает слова, символы и число совпадений поисковой фразы без учёта регистра.

## Где находится код

| Файл | Ответственность |
| --- | --- |
| frontend/src/modules/TextEditor.jsx | Документ, библиотека, импорт/экспорт, поиск и состояние интерфейса |
| frontend/src/modules/workspace-modules.css | text-document, document-stats, library-item и общие панели |
| frontend/src/api/documents.js | listDocuments, getDocument, saveDocument, deleteDocument |
| frontend/src/api/client.js | fetch, обработка HTTP-ошибок и ответа 204 |
| backend/Controllers/DocumentsController.cs | Маршруты документов, ответы 200/204/400/404 |
| backend/Models/Document.cs | DTO запроса, модели документа и списка, атрибуты проверки |
| backend/Data/DocumentRepository.cs | SQL чтения, сохранения и удаления |
| backend/Data/HubDatabase.cs | Создание таблицы documents |

Отдельного DocumentService нет: ограничений DTO достаточно, контроллер передаёт проверенную модель репозиторию. Если появятся преобразования текста или бизнес-правила, их стоит вынести в сервис.

## Состояние

| Значение | Назначение |
| --- | --- |
| documentId | id открытого/сохранённого документа; null для нового |
| name, text | Текущий буфер названия и текста |
| documents | Список документов из SQLite |
| search | Поисковая фраза; matches вычисляется из текста |
| dirty | Есть изменения, ещё не сохранённые в библиотеку |
| busy | Блокирует редактирование и повторные запросы во время сохранения/открытия |
| message | Результат последнего действия или ошибка |
| fileInput | Ссылка на скрытый input выбора TXT |

## Функции

| Функция | Действие |
| --- | --- |
| mayReplaceDocument | Просит подтвердить замену несохранённого буфера |
| newDocument | Очищает буфер и id после подтверждения |
| refreshLibrary | Загружает список, не меняя текущий текст |
| openDocument | Проверяет dirty, читает документ и заполняет буфер |
| persistDocument | Создаёт UUID один раз, затем обновляет тот же документ |
| removeDocument | После подтверждения удаляет запись; текущий текст остаётся в буфере с новым несохранённым состоянием |
| importText | Читает File.text() как UTF-8 и создаёт несохранённый документ |
| exportText | Создаёт Blob, временный URL и скачивает TXT; URL затем освобождается |

words считает фрагменты между пробельными символами. matches считает неперекрывающиеся совпадения и не выделяет их на экране. Статистика символов использует JavaScript string.length (кодовые единицы UTF-16; эмодзи могут занимать больше единицы).

## API и хранение

```text
TextEditor → api/documents.js → request → DocumentsController
→ DocumentRepository → SQLite documents
```

| Метод | Адрес | Запрос / ответ |
| --- | --- | --- |
| GET | /api/documents | Массив id, name, updated |
| GET | /api/documents/{id} | id, name, content; 404, если нет |
| PUT | /api/documents/{id} | JSON name, content; ответ id |
| DELETE | /api/documents/{id} | 204 при удалении, 404, если нет |

Таблица documents: id TEXT PRIMARY KEY, name TEXT, content TEXT, updated TEXT. Время обновления — UTC ISO 8601. Имя обязательно, до 200 символов; текст до 1 млн символов. Пустой текст разрешён, null — нет. Data Annotations и ApiController автоматически возвращают 400 при нарушении ограничений. SQL использует параметры.

## Поведение и ограничения

Импорт ограничен 4 млн байт и 1 млн символов после чтения. Скачивание создаёт файл, не перезаписывает исходник. dirty сбрасывается только после сохранения в SQLite; скачивание TXT не считается записью в библиотеку. После перезагрузки сохранённое открывается кнопкой «Библиотека»; несохранённый буфер теряется. Подтверждение замены действует для команд Новый, открытия и импорта внутри модуля; системное закрытие вкладки не перехватывается.

Нет DOCX, разметки, форматирования шрифтов и совместного редактирования. Сервер нужен для библиотеки, но не для ввода и TXT. Удаление из базы необратимо через интерфейс; открытый буфер сохраняется для возможного повторного сохранения.

## Проверка

Создайте документ с кириллицей, переносами строк и эмодзи; найдите фразу с другим регистром. Сохраните, отредактируйте и сохраните снова: в библиотеке должна остаться одна запись. Перезагрузите страницу, откройте из библиотеки. Проверьте пустой текст, импорт/скачивание TXT, подтверждение замены и удаление. При выключенном сервере текст и экспорт должны оставаться доступными.
