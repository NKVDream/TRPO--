# Органайзер

Модуль `organizer`, адрес `#organizer`. Хранит задачи с названием, заметками, сроком, приоритетом и признаком выполнения. Поддерживает создание, редактирование, удаление, поиск и фильтры. Данные сохраняются в SQLite.

## Где находится код

| Файл | Ответственность |
| --- | --- |
| frontend/src/modules/Organizer.jsx | Форма, список, фильтрация, статистика, HTTP-действия |
| frontend/src/modules/workspace-modules.css | task-form, task-list, task-card, task-meta, task-stats |
| frontend/src/api/tasks.js | listTasks, saveTask, deleteTask |
| backend/Controllers/TasksController.cs | Маршруты, проверка календарной даты |
| backend/Models/OrganizerTask.cs | Модель задачи и атрибуты проверки входного JSON |
| backend/Data/TaskRepository.cs | SQL списка, INSERT/UPDATE и DELETE |
| backend/Data/HubDatabase.cs | Таблица tasks |

Отдельного сервиса нет: DTO проверяет поля, контроллер — формат даты, репозиторий отвечает за SQL. Это небольшой CRUD-модуль, без планировщика фоновых событий.

## Состояние и вычисления

tasks — загруженный список; form — буфер title, notes, dueDate, priority, completed; editingId — id редактируемой задачи либо null. filter выбирает все/в работе/выполненные, query ищет по заголовку и заметкам. loaded отличает пустой результат от ещё не загруженного списка; busy блокирует пересекающиеся изменения; message показывает результат.

EMPTY_FORM задаёт начальные поля. PRIORITY_LABELS переводит low, normal, high в подписи. localDate вычисляет сегодняшнюю дату по локальной временной зоне браузера, без смещения через UTC. Задача просрочена, если не выполнена и dueDate меньше сегодняшнего дня. Задача со сроком сегодня ещё не просрочена.

Статистика вычисляется по всему загруженному списку, а не только по отфильтрованным карточкам. visibleTasks применяет фильтр выполнения и поиск без учёта регистра.

## Функции

| Функция | За что отвечает |
| --- | --- |
| updateForm | Меняет одно поле буфера, сохраняя остальные |
| resetForm | Возвращает пустую форму и отменяет режим редактирования |
| refreshTasks | Загружает сохранённые задачи с сервера |
| submitTask | Не даёт форме перезагрузить страницу; создаёт UUID либо обновляет editingId; пишет в API |
| editTask | Копирует задачу в форму, не изменяя БД |
| toggleCompleted | Сохраняет противоположное completed, затем обновляет список и открытый буфер |
| removeTask | Просит подтверждение, удаляет запись и закрывает форму удалённой задачи |

Состояние списка меняется после успешного ответа сервера. При ошибке задача не исчезает и введённые данные формы сохраняются. Создание и редактирование поддерживаются без отдельного API получения одной задачи — все нужные поля уже есть в GET списка.

## API и хранение

| Метод | Адрес | Назначение |
| --- | --- | --- |
| GET | /api/tasks | Полный список задач |
| PUT | /api/tasks/{id} | Создать или обновить задачу по id |
| DELETE | /api/tasks/{id} | Удалить; 204 или 404 |

Пример тела PUT:

```json
{
  "title": "Подготовить отчёт",
  "notes": "Добавить скриншоты модулей",
  "dueDate": "2026-11-02",
  "priority": "high",
  "completed": false
}
```

Пустой срок передаётся как null. Дата — только yyyy-MM-dd, без времени и зоны. Контроллер проверяет реальную календарную дату через DateOnly.TryParseExact. Приоритет — low, normal или high. Название обязательно, до 200 символов; notes до 10 000, пустая строка допустима, null — нет. Некорректный ввод даёт 400.

Таблица tasks: id TEXT PRIMARY KEY, title TEXT, notes TEXT, due_date TEXT NULL, priority TEXT, completed INTEGER. При загрузке SQL сортирует невыполненные перед выполненными, затем по сроку и названию. Локальное изменение списка добавляет обновлённую запись в конец; кнопка загрузки вновь применяет серверную сортировку.

## Ограничения и проверка

Нажмите «Загрузить задачи» после открытия/перезагрузки, чтобы получить полный список. Нет календарной сетки, повторяющихся событий, уведомлений и фоновых напоминаний. Изменения буфера формы до отправки не сохраняются автоматически.

Создайте задачи без срока, со сроком сегодня и в прошлом; проверьте статистику и подсветку просрочки. Измените название и приоритет, отметьте выполнение, проверьте поиск/фильтры. Перезапустите сервер и загрузите список. Удалите тестовую задачу. Отключите сервер во время сохранения: форма должна остаться заполненной, а сообщение — показать ошибку.
