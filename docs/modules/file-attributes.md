# Редактор атрибутов файлов

Модуль `files`, адрес `#files`. Пользователь загружает файл в рабочую папку C# сервера и меняет свойства этой копии. Исходный файл на компьютере не изменяется. Это явно указано в интерфейсе.

## Возможности и границы

Просмотр имени, размера и времени изменения; переименование; установка/снятие «только чтение»; изменение времени последней записи. Windows дополнительно поддерживает Hidden («скрытый»). На Linux/macOS переключатель Hidden недоступен: механизм dot-файлов не подменяет Windows-атрибут.

Скачать можно содержимое и имя копии. HTTP-скачивание не переносит ReadOnly/Hidden и время изменения в атрибуты скачанного файла: эти свойства применяются к файлу в рабочей папке сервера. Для проверки системных атрибутов смотрите именно её. Файловые разрешения также зависят от ОС и пользователя процесса; ReadOnly не является защитой от администратора.

## Где находится код

| Файл | Ответственность |
| --- | --- |
| frontend/src/modules/FileAttributes.jsx | Загрузка, список, выбор и форма свойств |
| frontend/src/modules/workspace-modules.css | file-library, file-item, file-details, workspace-checkbox |
| frontend/src/api/files.js | listFiles, uploadFile, updateFile |
| backend/Controllers/FilesController.cs | GET/POST/PUT/download; HTTP-ошибки и лимит запроса |
| backend/Models/WorkspaceFile.cs | Модель свойств и UpdateFileRequest |
| backend/Services/WorkspaceFileService.cs | Файловые операции, валидация имени, ограничение рабочей папкой |
| backend/Program.cs | Регистрация WorkspaceFileService в DI |

SQLite для файлов этого модуля не используется. Каждая копия лежит как `backend/data/files/{uuid}/{name}`. Эта папка исключена из Git. Метаданные читаются из файловой системы при запросе списка, поэтому не расходятся с состоянием копий после перезапуска.

## Фронтенд

| Значение / функция | За что отвечает |
| --- | --- |
| files, selectedId | Список рабочих копий и выбранный UUID |
| form | Редактируемые name, readOnly, hidden и modified |
| busy, message | Блокировка запросов и сообщения результата |
| localDateTime | Преобразует серверный UTC в значение datetime-local браузера |
| formatSize | Показывает байты либо КБ |
| selectFile | Копирует свойства в форму |
| updateForm | Меняет одно поле формы |
| refreshFiles | Загружает список; обновляет форму выбранного файла |
| importFile | Проверяет 20 МБ и отправляет FormData |
| applyAttributes | Преобразует локальное время в UTC ISO и отправляет PUT |

Неотправленные изменения формы живут в браузере; выбор другого файла или обновление списка их заменяет. Серверные файлы остаются между перезагрузками. Загрузка копии не открывает и не исполняет её.

## Серверный сервис

| Метод | Назначение |
| --- | --- |
| GetAll | Перечисляет UUID-папки и строит список свойств |
| FindPath | Принимает только UUID формата D, ищет файл внутри его папки, исключает символьные ссылки |
| IsValidName | Проверяет длину, управляющие символы, разделители, запрещённые символы, пробелы по краям и специальные имена Windows |
| UploadAsync | Создаёт UUID-папку и сохраняет поток; очищает частичный файл при ошибке |
| Update | Проверяет параметры, снимает ReadOnly, переименовывает, меняет время/Hidden и устанавливает выбранный ReadOnly |
| SetReadOnly | Меняет FileAttributes.ReadOnly через System.IO |
| Describe | Читает FileInfo и возвращает свойства и признак supportsHidden |

В Update время ограничено годами 1980–2100 для совместимости файловых систем. API не принимает произвольный путь. Имена вроде ../file, имена с разделителями и CON недопустимы при переименовании. Для загружаемого имени берётся только последний сегмент, чтобы имя от браузера не стало путём. Общий корень data считается доверенной папкой владельца приложения; API рассчитан на локальный запуск, не на многопользовательский публичный файловый сервер.

## API

| Метод | Адрес | Запрос / ответ |
| --- | --- | --- |
| GET | /api/files | Массив свойств рабочих копий |
| POST | /api/files | multipart/form-data, поле file; ответ свойства новой копии |
| PUT | /api/files/{id} | JSON name, readOnly, hidden, modifiedUtc; ответ обновлённые свойства |
| GET | /api/files/{id}/download | Содержимое как attachment application/octet-stream |

Модель ответа: id, name, size, readOnly, hidden, modifiedUtc, supportsHidden. При обновлении modifiedUtc может быть null: сохранить прежнее время. Ошибки ввода — 400, неизвестный UUID — 404, конфликт файловой операции — 409; превышение общего размера запроса может дать 413. Максимальная длина имени 180, размер файла 20 МБ плюс служебный запас для multipart.

## Проверка

Загрузите тестовый TXT, измените имя и время, включите ReadOnly, затем выключите. Проверьте FileInfo/системные свойства файла в data/files. Перезапустите сервер, загрузите список и сравните свойства. Скачайте содержимое и сравните байты. В Windows проверьте Hidden; на Linux — недоступность переключателя. Через API проверьте запрет имени ../outside.txt, некорректного UUID и времени вне диапазона. Исходный TXT вне папки сервера должен остаться неизменным.
