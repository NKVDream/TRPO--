
## Запуск

Нужны Node.js 18+ и .NET SDK 8.

Терминал 1, из корня репозитория:

```bash
dotnet run --project backend/Hub.csproj
```

Терминал 2:

```bash
cd frontend
npm install
npm run dev
```

Открыть адрес, напечатанный Vite (обычно http://127.0.0.1:5173). Vite перенаправляет `/api` на C# сервер, порт 5080.

## Единый запуск собранного приложения

```bash
cd frontend
npm ci
npm run build
cd ..
mkdir -p backend/wwwroot
cp -R frontend/dist/. backend/wwwroot/
dotnet run --project backend/Hub.csproj
```

Открыть http://127.0.0.1:5080. Сервер слушает только локальный интерфейс. База автоматически создаётся в `backend/data/hub.db`. Она не попадает в Git.

## Готовые модули

- Графический редактор: кисть, ластик, линия, прямоугольник, эллипс, цвет, толщина, отмена/повтор (до 25 состояний), импорт изображений, экспорт PNG, сохранение и открытие проектов в SQLite. Холст 1200×720; изображения вписываются с сохранением пропорций. Каждый клик «Сохранить» создаёт отдельный снимок проекта.
- Проигрыватель: локальные аудиофайлы, drag-and-drop, плейлист, воспроизведение/пауза, следующий/предыдущий трек, перемотка, громкость, случайный порядок, повтор трека, удаление. Поддержка кодеков зависит от браузера. Файлы не отправляются серверу, плейлист действует до перезагрузки страницы.
- Текстовый редактор: TXT UTF-8, поиск, статистика текста, импорт/экспорт, создание/открытие/обновление/удаление документов в SQLite.
- Органайзер: задачи, заметки, сроки, приоритеты, выполнение, поиск, фильтры, статистика и SQLite.
- Атрибуты файлов: загрузка рабочей копии до 20 МБ, имя, размер, ReadOnly, время изменения; Hidden только на Windows. Меняются копии в backend/data/files, не исходные файлы пользователя. Скачивание переносит содержимое и имя, но не системные атрибуты.

Открытые модули остаются смонтированными: переключение разделов сохраняет холст и музыку. Перезагрузка страницы сбрасывает несохранённые данные. Сервер нужен для библиотек рисунков/текста, задач и файловых атрибутов. Внешний шрифт необязателен: офлайн используется Arial.

## Автоматическая проверка API

После сборки backend:

```bash
python3 scripts/smoke_test.py
```

Тест запускает отдельный C# сервер со случайным локальным портом и временной базой. Проверяет документы, задачи, PNG-проекты, свойства файлов, ошибки и сохранность после перезапуска. Рабочая база приложения не затрагивается. Нужны Python 3 и доступ к локальным сокетам.
